A program that writes one funny passive-aggressive note a smart fridge leaves for its owner. The fridge kept the yogurt at 3 degrees for six days and counting; the yogurt has outlived three of the owner's diets without even trying, so the fridge is already starting to root for the yogurt. The note is written to `/output/entry.txt` for the make.fun bounty.

## Run it

```sh
python3 main.py
```
